# AirBnB Clone Project

This project is a full-stack clone of the popular accommodation booking platform AirBnB which is to be built as part of my ALX ProDev Frontend Development. The goal is to build a functional web application that allows users to browse property listings, view detailed property information, and complete bookings. The project will cover frontend development, backend APIs, database design, and deployment.

# Tech Stack To Be Used
 Frontend: HTML, CSS, and JavaScript (React js)

# UI/UX Design Planning
Design goals that need to be implemented are: 
- Create intuitive booking flow
- Maintain visual consistency
- Ensure fast loading times
- Prioritize mobile responsiveness

Key features that need to be implemented are:
- Property search and filtering
- Detailed property viewing
- Secure checkout process
- User authentication

Descriptions of the three primary pages are: 
- Property Listing View
- Detailed View
- Simple Checkout View

Your ability to make your application user-friendly is necessary because it eases software usage for users
