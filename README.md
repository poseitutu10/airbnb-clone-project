# AirBnB Clone Project

This project is a full-stack clone of the popular accommodation booking platform AirBnB which is to be built as part of my ALX ProDev Frontend Development. The goal is to build a functional web application that allows users to browse property listings, view detailed property information, and complete bookings. The project will cover frontend development, backend APIs, database design, and deployment.

# Tech Stack To Be Used
 Frontend: HTML, CSS, and JavaScript (React js)
